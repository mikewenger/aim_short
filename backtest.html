What this does and doesn't do: every fill in this backtest comes from Massive's real historical bars for the underlying and for the specific 0DTE option contract traded — nothing here is simulated or estimated. If Massive doesn't return real options data for a step (contract listing or intraday pricing), the run stops immediately and tells you exactly which call failed, instead of guessing a price. This is a historical simulation, not investment advice, and past signals don't guarantee future fills at these prices (real-world slippage/spread aren't modeled beyond the actual quoted bar prices returned).

📈 Long Leg — Buy Calls
Entry: RSI confirms a reversal down from a peak above the overbought threshold → buy calls at the open of the next available tick.
📉 Short Leg — Buy Puts
Entry: RSI confirms a reversal up from a trough below the oversold threshold → buy puts at the open of the next available tick.
Signal Logic
  • RSI(period) computed with Wilder smoothing over the full history window (not just the backtest day), so the very first in-session bar has a real warmed-up value
  • "Peak over threshold, confirmed reversal" = the first bar-over-bar decrease in RSI immediately following any bar where RSI was above the overbought threshold
  • Symmetric rule for troughs: first bar-over-bar increase following any bar below the oversold threshold
  • Each leg re-arms after its position closes — a leg can trade more than once in a session if RSI oscillates again
Fill & P&L Logic
  • Entry price = real option price at the open of the first available tick at/after the signal bar closes
  • Intra-trade P&L is marked from real option aggregate bars — 1-second bars if Massive returns them, otherwise 1-minute (whichever was actually used is logged per trade)
  • Position exits the instant marked P&L reaches the profit target, or is force-closed at session end (0DTE) if the target is never hit — in that case the maximum P&L reached intraday is reported alongside the actual (smaller) realized result
  • If Massive can't supply real contract or price data at any step, the run stops and reports the exact failure instead of guessing
